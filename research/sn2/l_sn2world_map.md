## Streaming facts (VERIFIED 2026-11-18 from the game log / exe)
Relevant to the open "never load SN2 terrain" design (when L_Main is used, e.g. for the real SN2 world).
- Single player runs NetMode Standalone (`IsServerStreamingEnabled = 1`).
- Cells load inside `LoadMap` in the same frame (frame 636 map load, `Attempting to find player start with tag Shallows`; `Applying start conditions of Shallows` 1.1 s later). UE4SS BPModLoaderMod spawns ModActors from `RegisterLoadMapPostHook` (after `LoadMap` returns), so a ModActor in L_Main is always too late to stop the first cells; anything that must prevent loading has to be set before `LoadMap(L_Main)`, e.g. from the ModActor spawned in the lobby.
- `L_ClientLobby` is not a World Partition map.
- The game mode spawns a per-player WP source during login: `AUWEGameModeBase.TempPlayerSpawnStreamingProxies : TMap<APlayerController*, AUWEStreamingSourceProxyActor*>` (`AUWEStreamingSourceProxyActor.StreamingSourceComponent : UWorldPartitionStreamingSourceComponent`, methods `DisableStreamingSource/EnableStreamingSource/IsStreamingCompleted`). `APlayerController` has `bEnableStreamingSource`, `bStreamingSourceShouldActivate`, `bStreamingSourceShouldBlockOnSlowStreaming`.
- WP cvars in the exe strings: `wp.Runtime.UpdateStreamingSources` (0 = freeze sources), `wp.Runtime.OverrideRuntimeSpatialHashLoadingRange`, `wp.Runtime.EnableServerStreaming` (read only at start), `wp.Runtime.PlayerController.ForceUsingCameraAsStreamingSource`, `wp.Runtime.DumpStreamingSources`, `wp.Runtime.MaxLoadingStreamingCells`. Game cvars: `uwe.*`, `sn2.*`.
- Spawn systems (Headers.hpp): `UUWEWorldPopCreaturesSubsystem` (`bIsCreatureSubsystemEnabled`, `DisabledClasses`, `RequestSpawnManagedCreature`), `UUWEWorldPopSubsystem` (`ResourcesToRespawn`), `UUWEAIDirectorSubsystem`, `AUWEAISpawner`; creature bases `AUWEAIPawn` (-> `AUWEAILargeFish`, `AUWEAISmallFish`) and `AUWEAICharacter`.

## Mod SN2EmptyWorld (design and build, 2026-11-18)
- Design (chunk 2; only lifepod, ocean and sky survive, from a cooked modkit mod, not Lua): (1) cells never load: the lobby ModActor runs `ExecuteConsoleCommand("wp.Runtime.UpdateStreamingSources 0")`; (2) the L_Main ModActor destroys every `_UAID_` actor not on the keep-list (lifepod, ocean, sky, invisible managers, any `PlayerStart` subclass) plus `UWEWorldPopGlobalResourcesDataStorage` plus any `UWEAIPawn`/`UWEAICharacter`, repeating every 1 s with `CollectGarbage` when something was destroyed; (3) measured by the read-only `SN2Census` Lua mod (see `research/code/README.md`). Not avoidable: `L_Main.umap` itself (1,668 persistent actors) loads before the purge; only replacing `L_Main` avoids that. Built by `src/modkit/scripts/sn2emptyworld_graph.py`, scaffold `/Game/Mods/SN2EmptyWorld/{ModActor, PAL_SN2EmptyWorld}`, cook 157 s, installed as LogicMods/SN2EmptyWorld.
- Final ModActor graph (106 nodes): BeginPlay -> `wp.Runtime.UpdateStreamingSources 0` -> branch on level name: `L_Main` purge; `L_ClientLobby` `SetWorldLevel("/Game/Mods/SN2EmptyWorld/L_SN2World")` then destroy self; else destroy self.
- Graph facts: `get_class_display_name(BP_Ocean_C)` keeps `_C`; keep-list has 16 entries (`WaterZone`, `PCGWorldActor` native, no `_C`). `unreal.UWEAIPawn` does not exist, use `unreal.load_class(None, "/Script/<Module>.<Name>")`. Class path `BP_PATH + ".ModActor_C"` is valid. `GetConsoleVariableIntValue` is impure (needs an Exec pin).
- Tests 2026-11-18 (VERIFIED): Test 1 purge in L_Main: World Tree gone, no terrain, water darker; 12.7 s load; 41 `_UAID_` actors remain; Shallows/Lifepod/Creative start at (-337209.42, 433378.55, 245.19) yaw -29; `LogInventory: Error: RemoveInventory will not remove inventory` is harmless. Test 2 `SetWorldLevel` dev map: loaded `L_GameplayZoo_SupplyCrates` (screenshot). Test 3 own map: loads, save/load works; 0.26 s LoadMap, working set about 0.4 GB below vanilla.
- OPEN (UNTESTED whether the purge mod causes it): default Deep start crash in L_Main with the purge: 18:54:02, AV READ 0x20 at exe+0x162AD90 right after "Applying start conditions of Deep" + `FlushAsyncLoading(15254): 4 QueuedPackages, 264 AsyncPackages` (see `research/process/core_rules.md` "Crashes" crash table).
