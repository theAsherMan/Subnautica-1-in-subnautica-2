## Streaming facts (VERIFIED 2026-11-18 from the game log / exe)
- Single player runs NetMode Standalone (`UWorldPartition::Initialize Context : World NetMode = Standalone, IsServer = 0 ... IsServerStreamingEnabled = 1`).
- Cells load inside `LoadMap` in the same frame (frame 636 in the 16:36 log: map load, player login, `Attempting to find player start with tag Shallows`, cell actors such as `BP_DoubleSlidingDoor_Repairable_C_UAID_...` and `BP_PCG_OR_NeedlerNeedles_C` all logged in frame 636; `Applying start conditions of Shallows` in frame 637, 1.1 s later). UE4SS BPModLoaderMod spawns ModActors from `RegisterLoadMapPostHook` (after `LoadMap` returns), so a ModActor in L_Main is always too late to stop the first cells loading. ## Mod SN2EmptyWorld (design and build, 2026-11-18)
- First test design (chunk 2; goal: only lifepod, ocean and sky survive, from a cooked modkit mod, not Lua; certainty that nothing from the SN2 world loads): (1) cells never load: the lobby ModActor runs `ExecuteConsoleCommand("wp.Runtime.UpdateStreamingSources 0")` and stores the `GetConsoleVariableIntValue` read-back in public vars; expected (UE source) an empty source list that is never refilled, so only always-loaded content loads; open risks were that SN2 blocks console commands from BP and that the game mode waits for the spawn proxy's streaming (loading-screen hang). (2) The L_Main ModActor destroys every `_UAID_` actor not on the keep-list (lifepod, ocean, sky, invisible managers, any `PlayerStart` subclass) plus `UWEWorldPopGlobalResourcesDataStorage` plus any `UWEAIPawn`/`UWEAICharacter` (counted safety net), repeating every 1 s with `CollectGarbage` when something was destroyed. (3) Measured by the read-only `SN2Census` Lua mod (cvar values, loaded `_Generated_` levels, actor counts by class, remaining `_UAID_` actors; see `research/code/README.md`). Not avoidable with this design: `L_Main.umap` itself (1,668 persistent actors) loads before the purge; only replacing `L_Main` with our own map avoids that. Built by `src/modkit/scripts/sn2emptyworld_graph.py`, scaffold `/Game/Mods/SN2EmptyWorld/{ModActor, PAL_SN2EmptyWorld}`, cook 157 s, installed as LogicMods/SN2EmptyWorld.
- Final ModActor graph (106 nodes): BeginPlay -> `wp.Runtime.UpdateStreamingSources 0` -> branch on level name: `L_Main` purge; `L_ClientLobby` `SetWorldLevel("/Game/Mods/SN2EmptyWorld/L_SN2World")` then destroy self; else destroy self.
- Graph facts: `get_class_display_name(BP_Ocean_C)` keeps `_C`; the keep-list has 16 entries (`WaterZone`, `PCGWorldActor` native, no `_C`). `unreal.UWEAIPawn` does not exist, use `unreal.load_class(None, "/Script/<Module>.<Name>")`. Class path `BP_PATH + ".ModActor_C"` is valid, `BP_PATH + "_C"` is not. `GetConsoleVariableIntValue` is impure (needs an Exec pin; pruned otherwise).
