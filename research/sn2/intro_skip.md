## Blueprint disassembly: how the intro really works (2026-11-18, VERIFIED from cooked assets; override behaviour VERIFIED later, see Command line)
- Tooling (on `<ModkitDir>`'s drive): `retoc to-legacy --no-shaders --version UE5_6 -f <NamePart> <GameDir>\Subnautica2\Content\Paks <out>` (pass the Paks **directory**, not the .utoc; `-f` is a name filter) gives legacy `.uasset/.uexp`. Parse with UAssetAPI 1.1.0 (dotnet 8, NuGet): `new UAsset(path, EngineVersion.VER_UE5_6, new Usmap("<Automation>\Subnautica2-131439.usmap"))`, `SerializeJson()`, bytecode in `FunctionExport.ScriptBytecode`. Jump targets in the Kismet bytecode = sum of `expr.Write()` sizes plus the statement index. Scratch in `<ModkitDir>\scratch_bp\` with disassembler `tools\kdis.py`.
- Start system: every spawn applies the conditions of one `ASN2PlayerStart` actor (class `BP_*PlayerStart`, C++ `AUWEPlayerStart::ApplyStartConditions`, log line `Applying start conditions of <PlayerStartTag> to player`). CDO data: `PlayerStoryGoals, UnlockStoryGroups, InventoryItems, EquippedItems, GrantTags, RemoveTags, AppliedEffects, bSetTimeOfDay/TimeOfDay, DefaultForGameModeClass, PlayerStartTag`. Survival's start = `BP_DeepPlayerStart` (tag `Deep`, `DefaultForGameModeClass = BP_SN2WorldGameMode_C`); Creative's = `BP_CreativeModePlayerStart` (tag `Creative`, `DefaultForGameModeClass = ..._CreativeMode_C`).
- `BP_DeepPlayerStart` = the intro. `GrantTags = [Character.State.HideUI, Adaptations.Missing.Breathing]`, `AppliedEffects = [GE_BreathingAdaptationMissing_C, GE_DeepstartHealthLoss_C]`. `OnStartConditionsApplied`: `WorldEventTracker.Notify(EventTracker.DeepStart.PlayersStarted)`; if the lifepod already launched -> `Manager.AssignLatePlayer(pawn, true)`; else hide pawn, `AssignToBiobed`, add global tag `Gamestate.DeepStartIntro`, `DeepStartIntroTrigger.Trigger`, `BioBed.PlayDeepStartBiobedAnim(pawn)`, spawn `BP_DeepStartPreparePlayerHandler`; the tag is removed again when the `FirstTimeAtSurface` goal unlocks.
- `BP_CreativeModePlayerStart`: `OnPreSpawnReady` -> `ClientPushScreenToLayer(WBP_CharacterIntroScreen_C, 6)` (character select); `OnStartConditionsApplied` -> `BP_LifepodManager_C:ApplyCreativeModeStart(pawn)`. Data: goals `Ch2_FirstTimeAtSurface`, `Ch1_LifepodsFound`, `Ch1_FirstPrint`, `Ch1_AdaptationTutorial1`; group `StoryGroup.Deepstart`; InventoryItems Flashlight, Scanner, Builder, Wakemaker, SonicResonator, Flares, SurvivalMultiTool; EquippedItems OxygenTank_Medium, ImprovedFins; RemoveTags `Character.State.HideUI`, `Adaptations.Missing.Breathing`; time 0.25.
- Cheats come from the game mode, not the start: `BP_SN2WorldGameMode_CreativeMode` CDO `GameSettingsOverrides` (`FUWEGameConfigSettings`): `bInvisibleToHostiles, bEnableNoCost, bUnlockAllBioAbilities, bUnlockAdaptations, bUnlockAllBiomodSlots, bUnlockAllRecipes, CraftingSpeedMultiplier 3, QuickProccessing, bEnableUnlimitedPower, bUnlockAllScanningFilters, bInvulnerable, bBlockOxygen/Food/WaterConsumption ...` (source of the `Cheat.*` / `DamageImmunity.*` / `Adaptations.*` global tags in the 2026-11-18 Creative log).
- `BP_ShallowsPlayerStart` (tag `Shallows`) is exactly "intro skipped, nothing else": goal `Ch2_FirstTimeAtSurface`, group `StoryGroup.Deepstart`, RemoveTags `[Character.State.HideUI, Adaptations.Missing.Breathing]`, time 0.25, no InventoryItems, no EquippedItems, no GrantTags. Other starts: `Farmlands/Pinnacles/Karakorum` (Deepstart group + small tank + fins only), `FreeBuild` (Builder + ImprovedFins + Cheat.GodMode...), GoldenPath `BP_01..10_*` (story checkpoints with full kits), `Phototour`, `BlightEncounter`, `Graveyard*`, `SparsePlains_LeviathanZone_A/B`.
- `BP_LifepodManager_C` `ReceiveBeginPlay` (ubergraph entry 4408): `GetGameModeType`; Creative binds nothing (no intro listeners); Survival/None binds `OnLifepodLaunched` (story goal `DA_Player_Ch1_LifepodRide1_StoryGoal` starts the Bink ride video) and `OnPlayerJoinedReady_Event` (-> `AssignLatePlayer(pawn,false)`, a no-op until the pod has launched). `HasLifepodBeenLaunched()` = story goal `LifepodArriveSG` unlocked OR global tag `Gamestate.LifepodAscending`. `ApplyCreativeModeStart(Character)`: if not launched -> `LifepodEndLogic()` (ubergraph 7800, the `OnLifepodArrived` chain); then `AssignLatePlayer(Character,false)`. `AssignLatePlayer` (only when launched): `Character.SetLifepodRideCompleted()`, `AssignPawnToBioBed(static surface lifepod bed)`, `RemoveGlobalTag(Gamestate.DeepStartIntro)`, ASC persistent tags: `Character.State.HideUI` off, `Adaptations.Missing.Breathing` off, `UI.PDA` off, `Adaptations.Breathing` on, remove effect `GE_BreathingAdaptationMissing_C`.
- **Command line:** the shipping exe contains the strings `OverridePlayerStart=`, `ChoosePlayerStart`, `FindPlayerStart`, `PlayerStartTag`. `Subnautica2-Win64-Shipping.exe -OverridePlayerStart=Shallows`: **VERIFIED 2026-11-18, tester**: new Survival game skips the whole intro, empty hotbar, only the breathing adaptation, free movement, player spawns in the lifepod; no Lua mod involved. `launch_game.sh` has `SN2_START=none` to disable the override. Start the exe directly with `SteamAppId=SteamGameId=1962700` while Steam runs.
