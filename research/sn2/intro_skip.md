## Intro skip: history and dead ends
Mods `SN2IntroProbe` (recorder, see Relevant classes) and `SN2IntroSkip` (v1-v5, `src/mods/SN2IntroSkip/Scripts/main.lua`) existed and are deleted. Recover: `git show 40820f3:src/mods/SN2IntroProbe/Scripts/main.lua`; SN2IntroSkip last commit `b949409` (earlier `e9aad1d`).
Skip v4 (VERIFIED 2026-11-17, tester "It worked perfectly"): arming = a `PlayerController:ClientRestart` hook arms the mod only if the hook's own controller (`ctx:get():GetWorld():GetFullName()`) is `L_Main`; in the lobby the mod runs nothing. Phase A (>= 1.5 s after the character spawns, pawn attached to a `*BioBed*`, `Ch2_EnteredLifepod` not unlocked): `BP_LifepodManager_C:ApplyCreativeModeStart(pawn)` plus 18 deep-start goals via `UWEStoryGoalsWorldSubsystem:UnlockStoryGoal(goal, pawn, true)` (18/18 OK), player stays in the bed. Phase B (pawn no longer attached to the bed, 26.0 s in that run, 45 s timeout): `K2_SetActorLocation(-336997, 433246, 322)`, `RemoveDeepStartTags(pawn)`, `SetLifepodRideCompleted(pawn)`, `UWEBioBedStatics:UnassignPawnFromBioBed` + `K2_DetachFromActor(1,1,1)`, `ResetIgnoreInputFlags`, `SetViewTargetWithBlend(pawn)`, `ShowAllPlayers`, `ShowHUD`. The 26 s wait also lets the pawn spawn at the right place relative to the pod. It was superseded by the start-condition route below.
Crash rules found while building it: never call methods on empty-result objects (`pawn:GetAttachParentActor():GetClass()` on an unattached pawn = UE4SS.dll access violation; helpers `nameOf/fullOf` check `isValid` first); never read `GetAdaptations()` complex structs; no periodic `FindAllOf` in the lobby (suspected cause of the 20 s `FinishDestroy` crash; with the recorder off the load succeeded 1 of 1, not statistically solid). See `research/process/core_rules.md` "UE4SS Lua rules".
Recording setup: for Recording 1 the terrain mods were disabled by moving `LogicMods\SN2Terrain` to `<Workspace>\disabled_mods\SN2Terrain` (reinstall by moving it back to `<GameDir>\Subnautica2\Content\Paks\LogicMods\`) and setting `SN2TerrainEdit : 0` in `ue4ss\Mods\mods.txt`; `SN2IntroProbe : 0` plus removing its `enabled.txt` disables the recorder (re-check the no-`FindAllOf`-in-lobby rule before enabling it again). State on 2026-11-17: SN2Terrain was not installed (parked); the ModActor is also spawned in the lobby (self-destroys there; gate it to `L_Main`).

## Blueprint disassembly: how the intro really works (2026-11-18, VERIFIED from cooked assets; behaviour of the override UNTESTED)
(Override behaviour was VERIFIED later, see Command line below.)
- Tooling (all on `<ModkitDir>`'s drive, nothing on C:): `retoc to-legacy --no-shaders --version UE5_6 -f <NamePart> <GameDir>\Subnautica2\Content\Paks <out>` (pass the Paks **directory**, not the .utoc; `-f` is a name filter) gives legacy `.uasset/.uexp`. Parse with UAssetAPI 1.1.0 (dotnet 8, NuGet): `new UAsset(path, EngineVersion.VER_UE5_6, new Usmap("<Automation>\Subnautica2-131439.usmap"))`, `SerializeJson()`, bytecode in `FunctionExport.ScriptBytecode`. Jump targets in the Kismet bytecode = sum of `expr.Write()` sizes plus the statement index. Scratch in `<ModkitDir>\scratch_bp\` with disassembler `tools\kdis.py`.
- Start system: every spawn applies the conditions of one `ASN2PlayerStart` actor (class `BP_*PlayerStart`, C++ `AUWEPlayerStart::ApplyStartConditions`, log line `Applying start conditions of <PlayerStartTag> to player`). CDO data: `PlayerStoryGoals, UnlockStoryGroups, InventoryItems, EquippedItems, GrantTags, RemoveTags, AppliedEffects, bSetTimeOfDay/TimeOfDay, DefaultForGameModeClass, PlayerStartTag`. Survival's start = `BP_DeepPlayerStart` (tag `Deep`, `DefaultForGameModeClass = BP_SN2WorldGameMode_C`); Creative's = `BP_CreativeModePlayerStart` (tag `Creative`, `DefaultForGameModeClass = ..._CreativeMode_C`).
- `BP_DeepPlayerStart` = the intro. `GrantTags = [Character.State.HideUI, Adaptations.Missing.Breathing]`, `AppliedEffects = [GE_BreathingAdaptationMissing_C, GE_DeepstartHealthLoss_C]`. `OnStartConditionsApplied`: `WorldEventTracker.Notify(EventTracker.DeepStart.PlayersStarted)`; if the lifepod already launched -> `Manager.AssignLatePlayer(pawn, true)`; else hide pawn, `AssignToBiobed`, add global tag `Gamestate.DeepStartIntro`, `DeepStartIntroTrigger.Trigger`, `BioBed.PlayDeepStartBiobedAnim(pawn)`, spawn `BP_DeepStartPreparePlayerHandler`; the tag is removed again when the `FirstTimeAtSurface` goal unlocks.
- `BP_CreativeModePlayerStart`: `OnPreSpawnReady` -> `ClientPushScreenToLayer(WBP_CharacterIntroScreen_C, 6)` (character select); `OnStartConditionsApplied` -> `BP_LifepodManager_C:ApplyCreativeModeStart(pawn)`. Data: goals `Ch2_FirstTimeAtSurface`, `Ch1_LifepodsFound`, `Ch1_FirstPrint`, `Ch1_AdaptationTutorial1`; group `StoryGroup.Deepstart`; InventoryItems Flashlight, Scanner, Builder, Wakemaker, SonicResonator, Flares, SurvivalMultiTool; EquippedItems OxygenTank_Medium, ImprovedFins; RemoveTags `Character.State.HideUI`, `Adaptations.Missing.Breathing`; time 0.25.
- Cheats come from the game mode, not the start: `BP_SN2WorldGameMode_CreativeMode` CDO `GameSettingsOverrides` (`FUWEGameConfigSettings`): `bInvisibleToHostiles, bEnableNoCost, bUnlockAllBioAbilities, bUnlockAdaptations, bUnlockAllBiomodSlots, bUnlockAllRecipes, CraftingSpeedMultiplier 3, QuickProccessing, bEnableUnlimitedPower, bUnlockAllScanningFilters, bInvulnerable, bBlockOxygen/Food/WaterConsumption ...`. This is where the `Cheat.*` / `DamageImmunity.*` / `Adaptations.*` global tags in the 2026-11-18 Creative log come from (so the old v5 strip-after-the-fact approach was the wrong layer).
- `BP_ShallowsPlayerStart` (tag `Shallows`) is exactly "intro skipped, nothing else": goal `Ch2_FirstTimeAtSurface`, group `StoryGroup.Deepstart`, RemoveTags `[Character.State.HideUI, Adaptations.Missing.Breathing]` (= breathing works), time 0.25, no InventoryItems, no EquippedItems, no GrantTags. Other starts: `Farmlands/Pinnacles/Karakorum` (Deepstart group + small tank + fins only), `FreeBuild` (Builder + ImprovedFins + Cheat.GodMode...), GoldenPath `BP_01..10_*` (story checkpoints with full kits), `Phototour`, `BlightEncounter`, `Graveyard*`, `SparsePlains_LeviathanZone_A/B`.
- `BP_LifepodManager_C` `ReceiveBeginPlay` (ubergraph entry 4408): `GetGameModeType`; Creative binds nothing (no intro listeners); Survival/None binds `OnLifepodLaunched` (story goal `DA_Player_Ch1_LifepodRide1_StoryGoal` starts the Bink ride video) and `OnPlayerJoinedReady_Event` (-> `AssignLatePlayer(pawn,false)`, a no-op until the pod has launched). `HasLifepodBeenLaunched()` = story goal `LifepodArriveSG` unlocked OR global tag `Gamestate.LifepodAscending`. `ApplyCreativeModeStart(Character)`: if not launched -> `LifepodEndLogic()` (ubergraph 7800, the `OnLifepodArrived` chain); then `AssignLatePlayer(Character,false)`. `AssignLatePlayer` (only when launched): `Character.SetLifepodRideCompleted()`, `AssignPawnToBioBed(static surface lifepod bed)`, `RemoveGlobalTag(Gamestate.DeepStartIntro)`, ASC persistent tags: `Character.State.HideUI` off, `Adaptations.Missing.Breathing` off, `UI.PDA` off, `Adaptations.Breathing` on, remove effect `GE_BreathingAdaptationMissing_C`.
- **Command line:** the shipping exe contains the strings `OverridePlayerStart=`, `ChoosePlayerStart`, `FindPlayerStart`, `PlayerStartTag`. `Subnautica2-Win64-Shipping.exe -OverridePlayerStart=Shallows`: **VERIFIED 2026-11-18, tester**: new Survival game skips the whole intro, empty hotbar, only the breathing adaptation, free movement, player spawns in the lifepod; no Lua mod involved (UE4SS + the old probe mod loaded, no crash). A `steam://run/1962700//<args>/` URL did NOT start the game; start the exe directly with `SteamAppId=SteamGameId=1962700` while Steam runs. `launch_game.sh` has `SN2_START=none` to disable the override.
