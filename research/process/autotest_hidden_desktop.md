Split out of `autotest_input.md` in research pass 2 (2026-11-28); pass-1 text: `git show 3449200:research/process/autotest_input.md`. Options, refusals and timeouts: `autotest.md` "Hidden desktop is the default; mandatory test timeouts". Engine-mode input: `autotest_input.md`.

## Mechanism
- **Prototype `src/tools/hidden_desktop.py` (ctypes):** `CreateDesktopW("SN2Test")`, `CreateProcessW` with `STARTUPINFO.lpDesktop = "WinSta0\SN2Test"`, `EnumDesktopWindows`, `PrintWindow(PW_RENDERFULLCONTENT)` capture, `CloseDesktop`. Never calls `SwitchDesktop` unless `--show` / `--back` is given by hand. **VERIFIED (2026-11-22, `python src/tools/hidden_desktop.py selftest`):** notepad on the hidden desktop: window found on the desktop handle, 0 windows of that pid on the user's desktop (`EnumWindows`), PrintWindow 840x590 lum 245, desktop closed.
- **Holder process:** `launch` keeps the desktop handle open (`WaitForSingleObject` on the game process) and closes it only after the game exits; it also sets `SteamAppId` / `SteamGameId`. **VERIFIED (2026-11-22, probe + holder run):** `Subnautica2-Win64-Shipping.exe` stays on the hidden desktop (no Steam relaunch; Steam client running) and `hidden_desktop.capture` (GetWindowRect + GetWindowDC + PrintWindow flag 2) returned a real, non-black title-screen frame (lum 31).
- **Capture:** `GetClientRect` returns 0x0 for a window on another desktop, so `winshot.capture` falls back to `GetWindowRect` and drops `PW_CLIENTONLY`; `grab_win` crops the cross-desktop capture 1936x1119 (side/bottom border 8, title 31) to the 1920x1080 client, so all shots are 1920x1080 (VERIFIED in run 4).
- **Dialog on the hidden desktop (GOTCHA, VERIFIED 2026-11-22):** a force-killed run before the lobby leaves both marks; the next start shows the modal dialog (class `#32770`, title "Error", one `OK`) on the hidden desktop, where the user cannot see it. `EnumWindows` does not see it. `find_game_dialogs()` and `post_click()` therefore run in a worker thread attached with `SetThreadDesktop(OpenDesktopW("SN2Test"))` (`_on_hidden_desktop`; without it `EnumChildWindows` / `WM_GETTEXT` return nothing), then `PostMessageW(OK_hwnd, BM_CLICK)`; only an OK-only dialog is clicked, its text is logged. Dismissal in a run: UNTESTED (proven by hand only; no run hit the dialog since).
- Quit: after the main-menu quit steps the driver waits up to 30 s for the exe to exit; `autotest.sh` force-kills only if the exe is still up 60 s after the driver ends and appends `RUN DONE <verdict>` to `hidden_desktop_status.txt`. **Clean quit VERIFIED (2026-11-22):** driver.log `CLEAN QUIT path=main_quit exe_exited=True after 0.1 s`, no `forced_kill.txt`, holder closed the desktop; `running.dat` and `beforelobby.dat` absent afterwards (existence check only). Only force-kills leave the marks.
- **Rules:** keep the holder, the cross-desktop dialog dismissal, the cropped capture and the clean quit; never force-kill a hidden run before the lobby (the marks cause the modal dialog). Optionally wait for "Loading Shaders" to finish before Q2; add an unattended gamepad / XInput check if gamepads matter.
