# Autotest: OS-mode input facts, menu path by hand, lobby calls

Split out of `autotest.md` in research pass 2 (2026-11-28). OS keyboard/mouse input (`SendInput`) is opt-in (`--input os --visible`); the default is engine mode (`autotest_input.md`). The menu path and click centres still apply to engine-mode step definitions (`plans/menus.json`).

## Input injection facts, OS mode (VERIFIED 2026-11-18, autotest screenshots + log)
- UE4SS hotkeys fire on SendInput scan-code key events (`KEYEVENTF_SCANCODE`, modifiers held around the key).
- Menu clicks register via `MOUSEEVENTF_MOVE|ABSOLUTE` (x*65535/1919), 0.25 s hover, left down 80 ms / up. A click on a screen that is still animating in is sometimes ignored, so the driver repeats the click (max 3) while the screen did not change.
- Mouse look: relative `MOUSEEVENTF_MOVE` in chunks of 40 counts every 12 ms: **4.571 counts per degree for yaw and pitch**; +dx = turn right; +dy = look down; pitch clamps at +-89.9; error after one correction <= 0.1 deg over 8 x 45 deg turns. Calibration: `Ctrl+F11` -> move 600 counts -> `Ctrl+F11`, wrap handled.
- **Game-bound keys:** `F8` opens the in-game Feedback panel (mouse look dead, shots show the panel). Teleport hotkeys are therefore **Ctrl+Shift+Z / X / C / V / B** (waypoints 1-5), STATE is **Ctrl+F11**. Escape opens the pause menu.
- `ImageGrab.grab()` (Pillow, DPI aware) captures the game at 1920x1080, not black (mean luminance 23-54 in game).
- Focus: `SetForegroundWindow` with an Alt tap + `AttachThreadInput`, `GetForegroundWindow` checked before every input (abort = `FAIL_FOCUS`, exit 3). The window is gone after the last Exit click (expected, treated as DONE). The UE4SS GUI console (`GuiConsoleVisible = 1`) is a separate window; the driver refocuses the game before each action and screenshot.
- Run flow in OS mode: wait `[SN2AutoTest] WORLD L_ClientLobby` -> menu ready (two captures 1 s apart differ < 0.5; with `worldLevel` also the `worldLevel set` line, 2 s after the lobby line) -> menu clicks -> `PAWN possessed` (<= 240 s) -> settle 15 s -> per waypoint: teleport key, STATE, turn to front yaw / pitch 0 with the mouse (re-measure, up to 4 corrections, tolerance 3 deg), then for k=0..7: teleport key again, wait 3 s (k=0) / 0.8 s, screenshot, STATE, mouse +45 deg -> Escape-menu quit -> `taskkill` fallback after 60 s.

- **Character select does NOT appear on the new-game path for L_SN2World** (VERIFIED 2026-11-18: PLAY click -> `WORLD L_SN2World` + `PAWN possessed` within ~1 s, first in-game shot inside the pod). For L_Main see `research/sn2/l_sn2world_map.md` "Automated runs".
- Timings (LOGGED 2026-11-18): lobby line 16-21 s after launch; menu clicks to `PAWN possessed` ~15-20 s; L_SN2World LoadMap 0.75-1.25 s; one waypoint of 8 shots ~25 s; 40 shots + menus + quit ~6 min in OS mode.
- Gotchas: a waypoint above the sea (offset z +300) is a 3 m free fall (3 s later the pawn is 3-4 m underwater); at depth the player drowns (O2 45), so the pawn may die and respawn at deep/far waypoints (`autotest_input.md` death/respawn); STATE yaw/pitch come from `PlayerCameraManager:GetCameraRotation`.
