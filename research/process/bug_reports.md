## Bug reports from the user (F1 + bugshot_watch.sh) — built 2026-11-23
- User presses **F1** in game (mod SN2BugShot) -> `<ue4ss>/Mods/SN2BugShot/reports/<YYYYMMDD_HHMMSS>_<seq>.json`. The planner runs `bash src/tools/bugshot_watch.sh` under Monitor (long timeout, re-arm on expiry, persistent). It prints `WATCHING`, `GAME started pid=..`, `GAME exited` and ONE line per report:
  `BUGSHOT <id> [late] map=.. ue=(x,y,z) sn1=(x,y,z) depth=<m> hit=<actor|none> shot=<m> desc=<state|none> text="<first 150 chars>" dir=<Workspace>/bugshots/<id>`
  `late` = report older than the watcher start or older than 5 s. The folder holds report.json, screen.png (PrintWindow, if it worked), engine_shot.png, ue4ss_log_since_last.txt, game_log_since_last.txt, meta.txt, description.txt. The watcher then deletes the report json. It never sends input, kills or touches saves.
- **Screenshot methods:** (1) engine `HighResShot 1` via `KismetSystemLibrary:ExecuteConsoleCommand` from the mod -> `%LOCALAPPDATA%/Subnautica2/Saved/Screenshots/Windows/HighresScreenshot0000N.png`, 1920x1080, **VERIFIED (2026-11-23, autotest run 20261123_174947_bugshot, `bugshots/20261123_175151_001/engine_shot.png`: lifepod interior, open hatch, dark night ocean outside, player arm at right)**. Works on either desktop and needs no window, so it is the reliable method. (2) PrintWindow of the game window by the watcher: first run gave `shot=none(window client area is empty (0x0))` because `game_hwnd` took a 0x0 game window from the normal desktop. FIXED in code 2026-11-23 (enumerates normal + SN2Test desktops, ignores 0-area windows, takes the largest) but **UNTESTED**; the real F1 on the normal desktop is also untested.

## SN2BugShot popup (2026-11-24, F1 opens a description popup)
- Files: `src/mods/SN2BugShot/Scripts/{main,popup,bugshot}.lua`; widget in the modkit mod SN2BugShot (chunk 3, `/Game/Mods/SN2BugShot/WBP_BugReport`, vars DescBox / SubmitBtn / CancelBtn, int member Result 0 open / 1 submit / 2 cancel).
