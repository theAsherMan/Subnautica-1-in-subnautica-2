## SN2BugShot mod and collector (built 2026-11-23, installed + enabled)
- User presses **F1** in game -> `<ue4ss>/Mods/SN2BugShot/reports/<YYYYMMDD_HHMMSS>_<seq>.json`. The planner runs `bash src/tools/bugshot_watch.sh` under Monitor (long timeout, re-arm on expiry, persistent). It prints `WATCHING`, `GAME started pid=..`, `GAME exited` and ONE line per report:
  `BUGSHOT <id> [late] map=.. ue=(x,y,z) sn1=(x,y,z) depth=<m> hit=<actor|none> shot=<m> desc=<state|none> text="<first 150 chars>" dir=<Workspace>/bugshots/<id>`
  `late` = report older than the watcher start or older than 5 s. The folder holds report.json, screen.png (PrintWindow, if it worked), engine_shot.png, ue4ss_log_since_last.txt, game_log_since_last.txt, meta.txt, description.txt. The watcher then deletes the report json and never sends input, kills or touches saves. Copy reports to `<Workspace>\reports\` to keep them.
- `src/mods/SN2BugShot/Scripts/main.lua` binds F1 -> `bugshot.lua` (returns `report(source)`; also used by the SN2AutoTest verb `bugshot`, which loads `..\SN2BugShot\Scripts\bugshot.lua`). JSON fields (sorted keys): id, source, wallTime, gameTime, map, mapFull, ue{x,y,z}, unity{x,y,z}, depth, pawnRot, camera{loc,rot}, velocity, movementMode, attrs{oxygen,maxOxygen,health,maxHealth,food,water}, crosshair{hit,actor,class,component,mesh,distance,impact,normal,snTerrain}, vehicle, nearbyClasses50m (top 10), nearestSN1Terrain, engineShot{called,cmd}, ue4ssVersion.
- Quirks: `depth` = -Z/100 so it is NEGATIVE above the water (Z=0 ocean); camera rot read as all zeros (fix UNTESTED); attrs and crosshair VERIFIED correct in the autotest run (oxygen 45, hit BP_StaticLifepod_Surface_C_0).
