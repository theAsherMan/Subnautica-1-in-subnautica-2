## o2fill, podtp, envprobe verbs and `o2`, `views:"down45"` plan fields (2026-11-22)
- `o2fill`: calls `SN2CheatManager:Oxygen()` once per game (it is a toggle), then sets attribute `Oxygen` (CurrentValue and BaseValue) of `UWESurvivalAttributeSet` on the pawn's `UWEAbilitySystemComponent` (`SpawnedAttributes`, enumerated with ForEachProperty) to `MaxOxygen`. First two calls log `O2ATTR`/`O2FILL`. First version matched the wrong attribute (`DashOxygenCost`) and did not refill (FAILED 2026-11-22, run `20261122_171228_spot1_vis`); exact-name fix UNTESTED. `podtp` teleports the pawn to the spawn location.
- `envprobe <label>`: read-only, logs `ENVPROBE <label> ...` lines: camera, `REGION` actors (WaterLightSettings values), `OCEAN`, `HEIGHTFOG`, `POSTPROCESSVOLUMES`, `FOGSPHERES`, and every numeric pawn attribute (`ATTR set.name cur base`). VERIFIED (2026-11-22, same run). Survival attribute names: `Oxygen`, `MaxOxygen`, `Food`, `Water`. Plan `probe:"env"` calls it at the start of a `down45`/`abs8ud` waypoint.
- Driver: waypoint field `o2:true` sends `o2fill` before the waypoint and before/after turning for each shot; `views:"down45"` = 2 shots (k0 pitch -89, k1 pitch -45, yaw 0); `autotest.sh` EXPECTED counts 2 for `one` and `down45`.
- Driver `views:"burst"` (2026-11-28, UNTESTED in game): one pose (`yaw`/`pitch`/`fov` as `fixed`, optional `burstWait` s after the turn), then `frames` captures (default 8) spread evenly over `span` s (default 1.0; capture k due at k*span/frames), kept in memory and saved afterwards as `<idx>_<wp>_b<k>.png`. Logs per frame `BURST <file> t=<ms> grab=<ms> diff_prev=<mean abs grey diff to previous frame at 480x270>` (diff 0 = PrintWindow returned an unchanged frame). `autotest.sh` EXPECTED counts `frames` for it. Tool `src/tools/burst.sh` (research/process/burst.md "Burst comparison").
- `watersys <label>` verb (SN2AutoTest, 2026-11-26): read-only. Logs `WATERSYS <label> ...`: `SUBSYS`/`VOL[i]` (UWEBiomeTrackerSubsystem.Volumes with owner, loc, fog distance, albedo), `MPC S/V` (MPC_Biome parameter defaults and live values via `KismetMaterialLibrary:GetScalar/VectorParameterValue`), `BIOMEMAP` (CaptureRadius, WorldToBiomeMapScaleAndOffset, RenderTarget size, DefaultVolumeSettings), `SKY` (TimeOfDay, NormalizedDaylight, sun intensity), `PPC` (every PostProcessComponent: owner, enabled, unbound, priority, BlendWeight), `OCEANACTOR`, then runs `envprobe`. LOGGED (2026-11-26, run `20261126_181706_brownwater_sn2`). A `VolumeTrackerComponent` query (`FindAllOf("VolumeTrackerComponent")` + `GetCurrentVolumeType`/`IsInWater`/`GetDepth`) HUNG the game thread (command timeout, all later commands timed out; removed). Plans `brownwater_sn2.json` (two Safe Shallows poses) and `brownwater_lmain.json` (stock L_Main pod poses). The old plan-name-gated AUTOPIONEER Lua block was REMOVED 2026-11-27 (replaced by the menus.json `new_game_pioneer` chain, below).
