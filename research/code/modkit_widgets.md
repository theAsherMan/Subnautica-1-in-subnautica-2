- **Stub vs shipped class defaults (2026-11-27, implementer-water3, VERIFIED by run `20261127_204728_uwconfirm_sn2` vs `20261127_211152_uwconfirm_sn2`):** the modkit's stub C++ classes can have different defaults from the shipped game (`BiomeRegionVolumeType`: editor Shape, game Brush). A property saved with the editor default is NOT serialized, so the game falls back to ITS default. Such a value cannot be baked into the map; set it at runtime from the cooked ModActor graph (`KismetSystemLibrary.SetBytePropertyByName(Object, FName, uint8)` is BlueprintCallable, reachable with `SN2GraphLibrary.AddCallFunction`; used in `sn2emptyworld_graph.py`). The enum is not Python-exposed (`set_editor_property` -> 'Failed to convert property (EnumProperty)'), T3D paste only keeps values that differ from the archetype default, and flipping the umap name-table entry does not stick. Cooked map exports are RawExport (unversioned): uaa.exe shows `Data` as base64, so properties cannot be read from the cooked umap; read the editor T3D instead (`ocean_vt_read.py`).
