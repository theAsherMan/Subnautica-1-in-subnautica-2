## Driving the open editor from the shell
- `src/modkit/tools/ue_run.py` (+ copy of the engine's `remote_execution.py` beside it): `python -I ue_run.py <file.py>` runs a file in the editor, `python -I ue_run.py -c "<stmt>"` evaluates one statement and prints the editor's output. Needs Project Settings → Plugins → Python → **Enable Remote Execution?** (UDP multicast 239.0.0.1:6766 bound to 127.0.0.1, TCP 127.0.0.1:6776). Before it is enabled: `NO EDITOR FOUND` (exit 2). **VERIFIED 2026-11-16.**
- **Heavy lock (2026-11-19):** `ue_run.py` exits 5 (`HEAVY LOCK NOT HELD`) unless this session holds the lock (**VERIFIED**, scratch-dir test). Open the editor with `bash src/modkit/tools/launch_editor.sh` (acquires `editor`, runs `Launch-Editor.cmd`; UNTESTED with a real launch in the 2026-11-19 note). `cook_install.sh` acquires `cook`. See `research/process/heavy_lock.md`. `launch_editor.sh` fails if another session takes the idle lock between acquire and launch; use `SN2_LOCK_WAIT=<s>` to acquire and launch in one command.
- After a graph-tools build, the editor (started with `Start-Process Launch-Editor.cmd`; `cmd /c start` from Git Bash did NOT start it) took ~15 min until `ue_run.py` connected; early attempts fail with `NO EDITOR FOUND` then `Remote party failed to attempt the command socket connection!` (still starting): retry.
- Close the editor cleanly: `python -I src/modkit/tools/ue_run.py -c "unreal.SystemLibrary.quit_editor()"` (**VERIFIED 2026-11-28**; older form `execute_console_command(..., 'QUIT_EDITOR')` **VERIFIED 2026-11-19**).
- Fallback: the tester types `py "src/modkit/scripts/<file>.py"` in the editor's bottom `Cmd` box. Output goes to `Saved\Logs\Subnautica2.log` (`LogPython`).
- The editor keeps imported modules between `ue_run.py` runs: a shared helper next to the script needs `sys.path.insert(0, dirname(__file__))` and `importlib.reload(mod)`. `__file__` is defined in `MODE_EXEC_FILE`. **VERIFIED 2026-11-28.**
- SN2 Mod Tools facts (source `Plugins\SN2ModTools\Source\SN2ModTools\Private\ModActions.cpp`): "New mod" = `BlueprintFactory(ParentClass=AActor)` → `Content/Mods/<Mod>/ModActor` + `PrimaryAssetLabel` `PAL_<Mod>` (ChunkId = lowest unused 1–300, CookRule AlwaysCook, bLabelAssetsInMyDirectory).
