## Arbitrary meshes in the **editor** (modkit Python) — VERIFIED 2026-11-16 (asset built, cooked, visible + collidable in game)
Editor Python is the production path (cooked assets, `research/code/modkit_setup.md`). From Lua `AppendBuffersToMesh` FAILED (out-param error); one-call arbitrary mesh works from editor Python 2026-11-16 -> saved Nanite static mesh asset. The cooked terrain mod `SN2Terrain` (ModActor + SM_SeafloorTest, built by editor Python, pak chunk 1 in `LogicMods`) was **VERIFIED in game 2026-11-16** (visible at the Lua test spot + collision, the tester).
```python
buf = unreal.GeometryScriptSimpleMeshBuffers()
buf.set_editor_property("vertices", [unreal.Vector(x, y, z), ...])      # cm, Z up
buf.set_editor_property("uv0", [unreal.Vector2D(u, v), ...])
buf.set_editor_property("triangles", [unreal.IntVector(a, d, b), ...])  # a,b,d CCW-from-above came out facing -Z -> use a,d,b (or flip_normals)
dm = unreal.DynamicMesh()
unreal.GeometryScript_MeshEdits.append_buffers_to_mesh(dm, buf, 0, False)          # returns tuple
unreal.GeometryScript_Normals.recompute_normals(dm, unreal.GeometryScriptCalculateNormalsOptions())
mesh, outcome = unreal.GeometryScript_NewAssetUtils.create_new_static_mesh_asset_from_mesh(dm, "/Game/Mods/<Mod>/SM_x", opts)
```
101x101 grid (20k tris): buffers 58 ms, dynamic mesh 199 ms, asset creation + save 7.5 s. Full script: `src\modkit\scripts\sn2terrain_build.py`.

## 5. SN1 import design (plan, UNTESTED beyond the two cubes)
1. Extract SN1 terrain: voxel octrees per batch (160 m cubes, a 26x20x26 world); format decoded, pipeline in `research/sn1/README.md` and `extract.md`.
2. Mesh each batch (surface nets used) -> triangles + material ids; write chunk files (arbitrary-mesh path above).
3. Deliver: stream chunk files around the player into `DynamicMeshActor`s (proven for one 160 m grid chunk in 0.27 s), or cook them as static meshes with the modkit (used).
4. Clear SN2 underneath or place the map in open ocean and move the `BP_EdgeOfWorldVolume_C` ring; `BP_Ocean_C.BodySize` = 10 km x 10 km x 1 km.
5. Coordinates: SN1 is Y-up metres, SN2 is Z-up centimetres, both left-handed. **UE (X, Y, Z) = 100 * (unity.z, unity.x, unity.y) + offset**, quaternion UE (X, Y, Z, W) = (q.z, q.x, q.y, q.w) (UNTESTED derivation, `research/sn1/world_files.md` §3; the cube imports at these coordinates look right). The earlier formula (x*100, z*100, y*100) swaps two axes and would mirror the map; withdrawn (2026-11-19).
6. **Offset decision (2026-11-22):** offset (0, 0, 0): the SN1 origin is the `L_SN2World` origin (the lifepod start), SN1 sea level (y = 0) is the SN2 ocean surface (Z = 0). Spot-1 tiles sit at absolute UE coordinates (spot UE (21045, -124547, -26733) cm); tile actors at tile centres. The pod/ocean-surface alignment held in the origin check (`checks_origin.md`).
