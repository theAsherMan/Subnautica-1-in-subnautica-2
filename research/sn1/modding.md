## 11. Subnautica 1 modding and inspection (BepInEx + SN1Inspector), built 2026-11-22

Goal of this tooling: read live values (player position, biome, batch, nearby objects) from a running Subnautica 1 (SN1) to build and check the SN1 -> SN2 map pipeline. Status words as in `research/status.md`.

## SN1Inspector protocol (`src/sn1mods/SN1Inspector/Plugin.cs`)
I/O folder `<SN1Dir>/BepInEx/SN1Inspector/`:
- `status.txt`: rewritten every 0.5 s via temp file + `File.Replace`. Keys: `utc, frame, fps, scene, state (menu|loading|ingame), gamemode, newgame_session, pos (x= y= z= yaw= pitch=), depth, biome, batch (x-y-z)`. `state=menu` if `uGUI_MainMenu.main != null`; `ingame` if `Player.main`, `LargeWorldStreamer.main.IsReady() && IsWorldSettled()` and `!WaitScreen.IsWaiting`; else `loading`.
- `cmd.txt`: lines `<id> <verb> [args]`; the mod polls every 0.2 s on the main thread, reads then deletes the file; each id runs once (duplicates get `ERR duplicate id ignored`). Writers must write `cmd.tmp` then rename to `cmd.txt` (and only when `cmd.txt` is absent).
- `out.txt`: appended `<id> OK|ERR <text>`.
- Verbs: `help`, `pos`, `biome`, `batch`, `teleport x y z` (`Player.main.SetPosition`), `near <radius> [max]` (`Physics.OverlapSphere`, de-duplicated by `PrefabIdentifier` root, radius 0.5-500, max 1-200, prints name, position, distance, ClassId), `newgame creative` (`uGUI_MainMenu.main.OnButtonCreative()`), `skipintro` (`EscapePod.main.StopIntroCinematic(true)`), `shot <file.png>` (`ScreenCapture.CaptureScreenshot` into the io folder), `quit` (`Application.Quit()`, no save).
- Added 2026-11-24 (built + installed; `waterbiomes`, `hud`, `capture` **VERIFIED (2026-11-26)**: capture `shallow_ravine` gave a clean 1920x1080 PNG with no HUD, helmet or hands, and the pose JSON):
  - `waterbiomes <file>`: JSON with every `WaterBiomeManager.main.biomeSettings` entry (name, sky prefab, all `WaterscapeVolume.Settings` fields + derived `extinction = (absorption + scattering)·murkiness/100`, `scattering·murkiness/100`, scattering RGB, emissive), the loaded `AtmosphereDirector.main.GetVolumes()` (overrideBiome, priority, highDetail, affectsVisuals, fog fields, collider type/transform/size/bounds — streamed, so only volumes near the player), public scalar fields of the scene `WaterscapeVolume` (reflection), and the camera block below.
  - `hud on|off`: `HideForScreenshots.Hide(Mask|HUD|ViewModel)` / `Hide(None)`. Hides helmet mask, HUD and the arms/held tool (`HideType` flags: Mask 1, HUD 2, ViewModel 4).
  - `capture <name>`: hud off, 3 frames, writes `<name>.json` (camera pos/euler/yaw/`pitch_up`/fovV/fovH/aspect/screen, player pos, depth, `Player.GetBiomeString()`, `WaterBiomeManager.GetBiome(cam,false/true)`, the `GetSettings(cam)` water settings, `DayNightCycle.GetDayScalar()`), `ScreenCapture.CaptureScreenshot(<name>.png)`, waits 5 frames + end of frame, hud on. Reply comes late (coroutine).
- Live helper for a session the USER launched: `python src/tools/sn1_live.py status | cmd <verb..> | capture [name] [--biome B] | waterbiomes [name]` (capture writes into the repo's `samples/`, see `samples/README.md`) (no heavy lock, refuses exit 3 if Subnautica.exe is not running, reply timeout `--wait`, default 30 s, time-based ids). `capture` moves the files to `<Workspace>/sn1_shots/<name>/sn1.png|sn1.json` and writes `sn2_plan.json`, an autotest plan with one `views: "fixed"` waypoint (`at` = 100·(z, x, y) of the SN1 player, `yaw` = Unity yaw wrapped, `pitch` = pitch_up, `fov` = SN1 horizontal FOV). `status`, `waterbiomes`, `capture` **VERIFIED (2026-11-26)**: `waterbiomes safeShallows_dump --wait 60` -> `OK biomeSettings=145 atmosphereVolumes=107`; `capture shallow_ravine --wait 60` -> files + `sn2_plan.json`. The plan does not carry SN1 time of day (`dayScalar` is in `sn1.json`), and SN2 time is not set yet.
- The mod never saves. In-game verbs fail with `ERR not ingame (state=...)` while loading. **VERIFIED 2026-11-22** for every verb except `skipintro` (UNTESTED; Creative needs no skip).

## Harness: `src/tools/sn1_run.sh` + `sn1_run.py`
`bash src/tools/sn1_run.sh --timeout <s> [--check <s>] [--script <file>] [--no-launch]`. Refuses: no `--timeout` (exit 8), `Subnautica.exe` running (3), lock held (4), Steam not ready (6). Takes heavy lock kind `sn1` (`Subnautica.exe` was added to the default `SN2_HEAVY_PROCS` of `heavy_lock.sh`), releases it on exit.
- Backup of `SavedGames` to `<Workspace>/save_backups/sn1_<ts>/`; SHA256+mtime+size of every file before/after (`saves_pre.tsv`, `saves_post.tsv`, `save_compare.txt`; any change/missing pre-existing file = `FAIL_SAVES`); `reg export "HKCU\Software\Unknown Worlds"` before/after (`reg_diff.txt`). Never edits saves. Edits the registry only to restore the 4 `Screenmanager` display values to their pre-run values after exit (user-approved 2026-11-22).
- Launch: `hidden_desktop.py launch <Subnautica.exe> -screen-fullscreen 0 -screen-width 1280 -screen-height 720` with env `HD_APPID=264710` (new override; default stays 1962700), on desktop `SN2Test`. Never the visible desktop.
- Script verbs (`src/tools/sn1_scripts/default.sn1s`): `wait <state> [s]`, `cmd <inspector verb>`, `sleep <s>`, `hshot <file>`, `snap`. Default: wait menu, newgame creative, wait ingame, pos/biome/batch, teleport 0 -50 0, sleep 2, wait ingame 120 (added after run 1, UNTESTED), pos, near 30 20, shot, hshot, quit.
- Stop order: `quit` command, then `hidden_desktop.py close PID` (WM_CLOSE, new verb), then `taskkill /PID <launched pid> /F` logged `FORCED_KILL` (not needed in run 1).
- Run folder `<Workspace>/sn1_runs/<ts>/`: `run.log`, `result.txt` (DONE, DONE_NOQUIT, TIMEOUT, CRASH, FAIL_MENU, FAIL_NOPAWN, FAIL_NOSTATUS, FAIL_QUIT, FAIL_SAVES, FAIL_LAUNCH), `cmd_replies.txt`, `out.txt`, `LogOutput.log`, `Player.log`, `status_last.txt`, `shots/`, hash and registry files. With `--check N` it logs a CHECK line and a hidden shot every N s.
- **Test-world rule (user decision 2026-11-22):** a test must not leave a save slot. After the process has fully exited, delete only slot folders that are not in the pre-launch list AND were created after the run start (plain file delete, never the in-game delete), log each to `deleted_slots.txt` and `run.log`. Never delete `slot0000`, `slot0001`, `options` or anything pre-existing. If it is ambiguous which slot is the test's, or the game is still running, delete nothing and report. Offline test with a fake slot (`SN1_FAKE_NEWSLOT=1 ... --no-launch`): the fake slot was deleted, 59 pre-existing files unchanged. **VERIFIED 2026-11-22.**
- **Steam Cloud finding:** in run 1 the Creative game created **no** slot folder (new dirs `[]`), so nothing was deleted and Steam Cloud had nothing to resurrect or record. Whether a game that is saved leaves a slot, and whether Steam Cloud restores a deleted slot, is UNTESTED (only the fake-slot offline test ran: 30 s after deletion the folder had not come back, which says nothing about Steam). `steam_autocloud.vdf` existed before the run and was unchanged.

## Registry display values and auto-restore (2026-11-22)
- Unity writes display settings on exit to `HKCU\Software\Unknown Worlds\Subnautica` (NOT `...\Subnautica\Subnautica`). Four values, hash-suffixed: `Screenmanager Resolution Width_h182942802`, `Screenmanager Resolution Height_h2627697771`, `Screenmanager Fullscreen mode_h3630240806`, `Screenmanager Resolution Use Native_h1405027254`. Original: 1920, 1080, 1, 1. After a harness run (launched `-screen-width 1280 -screen-height 720 -screen-fullscreen 0`) they read 1280, 720, 3, 0. The `... Default_h...` variants are not changed. **VERIFIED 2026-11-22** (reg exports and reg query).
- Restored manually after run 1 (reg add, REG_DWORD, only these 4): back to 0x780 / 0x438 / 1 / 1. **VERIFIED 2026-11-22** (reg query).
- `sn1_run.py` now auto-restores: after `Subnautica.exe` is confirmed gone it compares the 4 values (prefix match) with `reg_pre.reg`, writes back changed ones, logs them to `<run>/reg_restored.txt`, `run.log` and `result.txt`, and records `reg diff after restore (Screenmanager lines): N` (expected 0). If the game is still running nothing is restored (`REG RESTORE SKIPPED`). The `unity.player_session_*` counters are left alone (they differ every run). **VERIFIED 2026-11-22** (run 2: 4 values restored, diff 0, reg query afterwards 0x780/0x438/0x1/0x1).
- Git Bash: registry switches need doubled slashes (`//v //t //d //f`).
