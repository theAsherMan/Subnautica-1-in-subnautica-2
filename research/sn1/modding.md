## SN1Inspector protocol (`src/sn1mods/SN1Inspector/Plugin.cs`)
I/O folder `<SN1Dir>/BepInEx/SN1Inspector/`:
- `status.txt`: rewritten every 0.5 s via temp file + `File.Replace`. Keys: `utc, frame, fps, scene, state (menu|loading|ingame), gamemode, newgame_session, pos (x= y= z= yaw= pitch=), depth, biome, batch (x-y-z)`. `state=menu` if `uGUI_MainMenu.main != null`; `ingame` if `Player.main`, `LargeWorldStreamer.main.IsReady() && IsWorldSettled()` and `!WaitScreen.IsWaiting`; else `loading`.
- `cmd.txt`: lines `<id> <verb> [args]`; the mod polls every 0.2 s on the main thread, reads then deletes the file; each id runs once (duplicates get `ERR duplicate id ignored`). Writers must write `cmd.tmp` then rename to `cmd.txt` (and only when `cmd.txt` is absent).
- `out.txt`: appended `<id> OK|ERR <text>`.
- Verbs: `help`, `pos`, `biome`, `batch`, `teleport x y z` (`Player.main.SetPosition`), `near <radius> [max]` (`Physics.OverlapSphere`, de-duplicated by `PrefabIdentifier` root, radius 0.5-500, max 1-200, prints name, position, distance, ClassId), `newgame creative` (`uGUI_MainMenu.main.OnButtonCreative()`), `skipintro` (`EscapePod.main.StopIntroCinematic(true)`), `shot <file.png>` (`ScreenCapture.CaptureScreenshot` into the io folder), `quit` (`Application.Quit()`, no save). `look`, `cam`, `chunkinfo`, `dumpterrain`: see `research/sn1/runs.md`.
- Added 2026-11-24 (built + installed; `waterbiomes`, `hud`, `capture` **VERIFIED (2026-11-26)**: capture `shallow_ravine` gave a clean 1920x1080 PNG with no HUD, helmet or hands, and the pose JSON):
  - `waterbiomes <file>`: JSON with every `WaterBiomeManager.main.biomeSettings` entry (name, sky prefab, all `WaterscapeVolume.Settings` fields + derived `extinction = (absorption + scattering)·murkiness/100`, `scattering·murkiness/100`, scattering RGB, emissive), the loaded `AtmosphereDirector.main.GetVolumes()` (overrideBiome, priority, highDetail, affectsVisuals, fog fields, collider type/transform/size/bounds — streamed, so only volumes near the player), public scalar fields of the scene `WaterscapeVolume` (reflection), and the camera block below.
  - `hud on|off`: `HideForScreenshots.Hide(Mask|HUD|ViewModel)` / `Hide(None)`. Hides helmet mask, HUD and the arms/held tool (`HideType` flags: Mask 1, HUD 2, ViewModel 4).
  - `capture <name>`: hud off, 3 frames, writes `<name>.json` (camera pos/euler/yaw/`pitch_up`/fovV/fovH/aspect/screen, player pos, depth, `Player.GetBiomeString()`, `WaterBiomeManager.GetBiome(cam,false/true)`, the `GetSettings(cam)` water settings, `DayNightCycle.GetDayScalar()`), `ScreenCapture.CaptureScreenshot(<name>.png)`, waits 5 frames + end of frame, hud on. Reply comes late (coroutine).
- Live helper for a session the USER launched: `python src/tools/sn1_live.py status | cmd <verb..> | capture [name] [--biome B] | waterbiomes [name]` (capture writes into the repo's `samples/`, see `samples/README.md`) (no heavy lock, refuses exit 3 if Subnautica.exe is not running, reply timeout `--wait`, default 30 s, time-based ids). `capture` moves the files to `<Workspace>/sn1_shots/<name>/sn1.png|sn1.json` and writes `sn2_plan.json`, an autotest plan with one `views: "fixed"` waypoint (`at` = 100·(z, x, y) of the SN1 player, `yaw` = Unity yaw wrapped, `pitch` = pitch_up, `fov` = SN1 horizontal FOV). `status`, `waterbiomes`, `capture` **VERIFIED (2026-11-26)**: `waterbiomes safeShallows_dump --wait 60` -> `OK biomeSettings=145 atmosphereVolumes=107`; `capture shallow_ravine --wait 60` -> files + `sn2_plan.json`. The plan does not carry SN1 time of day (`dayScalar` is in `sn1.json`), and SN2 time is not set yet.
- The mod never saves. In-game verbs fail with `ERR not ingame (state=...)` while loading. **VERIFIED 2026-11-22** for every verb except `skipintro` (UNTESTED; Creative needs no skip).

## Harness: `src/tools/sn1_run.sh` + `sn1_run.py`
`bash src/tools/sn1_run.sh --timeout <s> [--check <s>] [--script <file>] [--no-launch]`. Hidden desktop only, windowed 1280x720, Steam appid 264710 via `HD_APPID` (new override; default stays 1962700), desktop `SN2Test`. Refuses: no `--timeout` (exit 8), `Subnautica.exe` running (3), lock held (4), Steam not ready (6). Takes heavy lock kind `sn1` (`Subnautica.exe` is in the default `SN2_HEAVY_PROCS` of `heavy_lock.sh`), releases it on exit.
- Timing (**VERIFIED 2026-11-22**): plugin status 5 s after launch, menu 8 s, new Creative game to in-world 73 s, default script 90 s, exit 1 s after `quit`; use `--timeout 240` for the default script. After a teleport: `wait ingame 120` (state is `loading` for a moment), then `nearpoll <cap_s> <radius> [max]`; objects stream in over ~50 s (first creature after 53 s).
- Backup of `SavedGames` to `<Workspace>/save_backups/sn1_<ts>/`; SHA256+mtime+size of every file before/after (`saves_pre.tsv`, `saves_post.tsv`, `save_compare.txt`; any change/missing pre-existing file = `FAIL_SAVES`); `reg export "HKCU\Software\Unknown Worlds"` before/after (`reg_diff.txt`). Never edits saves.
- Registry auto-restore (**VERIFIED 2026-11-22**, run 2: 4 values restored, diff 0, reg query afterwards 0x780/0x438/0x1/0x1): after `Subnautica.exe` is confirmed gone it compares the 4 `Screenmanager` values (prefix match) with `reg_pre.reg`, writes back changed ones (the only registry edit, user-approved 2026-11-22), logs them to `<run>/reg_restored.txt`, `run.log` and `result.txt`, and records `reg diff after restore (Screenmanager lines): N` (expected 0). If the game is still running nothing is restored (`REG RESTORE SKIPPED`). The `unity.player_session_*` counters differ every run and are left alone.
- Launch: `hidden_desktop.py launch <Subnautica.exe> -screen-fullscreen 0 -screen-width 1280 -screen-height 720`. Never the visible desktop.
- Script verbs (`src/tools/sn1_scripts/default.sn1s`): `wait <state> [s]`, `cmd <inspector verb>`, `sleep <s>`, `hshot <file>`, `snap`, `nearpoll`. Default: wait menu, newgame creative, wait ingame, pos/biome/batch, teleport 0 -50 0, sleep 2, wait ingame 120, pos, near 30 20, shot, hshot, quit.
- Stop order: `quit` command, then `hidden_desktop.py close PID` (WM_CLOSE, new verb), then `taskkill /PID <launched pid> /F` logged `FORCED_KILL` (not needed in the runs so far).
- Run folder `<Workspace>/sn1_runs/<ts>/`: `run.log`, `result.txt` (DONE, DONE_NOQUIT, TIMEOUT, CRASH, FAIL_MENU, FAIL_NOPAWN, FAIL_NOSTATUS, FAIL_QUIT, FAIL_SAVES, FAIL_LAUNCH), `cmd_replies.txt`, `out.txt`, `LogOutput.log`, `Player.log`, `status_last.txt`, `shots/`, hash and registry files. With `--check N` it logs a CHECK line and a hidden shot every N s.
